# Zico · Распознавание фишинговых сообщений

Готовые файлы для GitHub и Vercel. Сайт не опубликован, ключи и база данных не подключены.

## Сначала посмотреть

Откройте `preview.html` двойным щелчком. Введение, цели, карта курса, модули, примеры и глоссарий открыты сразу. Для учебного прохождения нажмите «Войти» и выберите «Посмотреть без регистрации».
Это самостоятельная копия для просмотра. Она содержит оформление, пять модулей,
окно Zico и исходный модуль доставки. Настоящая регистрация, ответы Gemini и общая
статистика в ней не работают. Данные режима просмотра сохраняются в этом браузере,
если браузер разрешает локальное хранение. Не используйте preview.html для публикации.

Рабочий сайт начинается с `index.html`. Он использует отдельные CSS и JavaScript.
Для локального запуска установите Node.js 22 или новее и выполните `npm install`,
затем `npm run dev`. Откройте адрес, указанный в терминале.

## Что подготовлено

- Главная страница в зелёном оформлении исходного HTML.
- Вход и регистрация без электронной почты. Запоминается логин, но не пароль.
- Пять тем, всего 25 учебных ситуаций. На прохождение выбираются три без повторений.
- Случайный порядок ситуаций и вариантов ответа. Вопросы не генерируются ИИ.
- Роли, объяснение своими словами, подсказки и два маршрута обучения.
- Первые ответы сохраняются отдельно от повторных попыток.
- Личные результаты с выгрузкой JSON и синхронизацией с сервером.
- Zico в плавающем окне. Инструкция хранится на сервере в lib/prompt.js.
- Отдельный исходный модуль доставки из второй практической работы.
- Серверные обработчики аккаунтов, результатов, Gemini и статистики владельца.

## Структура

`assets/style.css` - оформление нового сайта.
`assets/app.js` - интерфейс, маршруты и окно Zico.
`assets/content.js` - учебные ситуации и варианты действий.
`modules/Фишинговые сообщения СМАРТ.html` - исходный модуль доставки.
`assets/delivery.css`, `assets/delivery.js` - вынесенные части исходного HTML.
`api/` - функции Vercel, выполняющиеся на сервере.
`lib/` - работа с базой, проверка ответов и инструкция Zico.
`schema.sql` - создание таблиц PostgreSQL.
`tests/` - автоматические проверки логики.
`preview.html` - автономный просмотр без установки.

Python для этого проекта не нужен. И интерфейс, и серверная часть используют JavaScript.

## Публикация на GitHub и Vercel

1. Создайте репозиторий GitHub и загрузите содержимое этой папки в его корень.
   Секретные ключи и файлы .env загружать нельзя. Файл .env.example содержит только пустые поля.
2. В Vercel добавьте проект через импорт этого репозитория.
3. Выберите Framework Preset `Other`. Если Vercel запросит настройки,
   Install Command - `npm ci`, Build Command оставьте пустым, Output Directory - `.`.
   На этом этапе можно опубликовать режим просмотра.
4. В Marketplace или Storage проекта подключите PostgreSQL, например Neon Free.
   Перед подтверждением проверьте, что выбран именно бесплатный план.
   Тарифы имеют квоты. Платный план для учебного запуска не требуется.
5. В SQL Editor базы выполните содержимое `schema.sql` один раз.
6. В Environment Variables проекта проверьте `DATABASE_URL`.
   Интеграция обычно добавляет строку подключения автоматически.
   Если имя другое, добавьте DATABASE_URL с той же строкой подключения.
7. Добавьте `GEMINI_API_KEY` со своим ключом и `GEMINI_MODEL` с ID текстовой модели,
   для которой в вашем AI Studio доступен Free Tier и есть квота.
   Пример поля - именно ID модели из AI Studio, а не её произвольное имя.
   Модель намеренно не выбрана за вас, чтобы не подключить платную или недоступную.
8. Сделайте Redeploy после добавления переменных.
9. Зарегистрируйте аккаунт на опубликованном сайте. Для статистики владельца
   в SQL Editor выполните `UPDATE zico_users SET is_admin=true WHERE username='ваш_логин';`.
   Подставьте свой логин. Из интерфейса сайта назначать администратора нельзя.
10. Проверьте регистрацию, выход и повторный вход, затем завершите модуль,
    обновите результаты с сервера и отправьте тестовый вопрос Zico.

GitHub хранит исходники, Vercel публикует сайт и выполняет серверные функции,
PostgreSQL хранит аккаунты и ответы, Gemini создаёт подсказки.
GitHub Pages не выполняет эти серверные функции.

## Что означают результаты

Автоматический балл относится к выбранному действию. Объяснение сохраняется дословно
и требует проверки преподавателем. Длина текста не означает правильность объяснения.
Набор адресов .example вымышленный, ссылки не открываются.
Банк вопросов конечный. После повторных прохождений ответы можно запомнить.
Обязательное объяснение и учёт первых попыток уменьшают пользу угадывания,
но не удостоверяют самостоятельность прохождения.

Общая статистика считает зарегистрированные аккаунты, завершённые ролевые прохождения,
уникальные аккаунты с результатами и успешные обращения к Gemini. Это не счётчик всех
посетителей, и аккаунт не равен уникальному реальному человеку. Просмотр без регистрации
не включён. Исходная доставка сохраняет SVG и локальную копию отдельно и пока не
включается в общую серверную статистику новых модулей.

## Учётные записи и данные

Пароли хешируются scrypt с отдельной солью. Сессии используют случайные токены,
в базе хранится хеш токена. Cookie HttpOnly, SameSite=Lax, в Vercel также Secure.
Сессия сохраняется до семи дней. Логин можно запомнить на устройстве. Пароль
в localStorage не записывается. Встроенного восстановления пароля пока нет.
Истёкшие сессии можно удалять SQL-командой из schema.sql.
Аккаунты, результаты и события обращений хранятся в PostgreSQL до ручного удаления владельцем.
Каскадное удаление пользователя удаляет связанные записи. Резервные копии и
политика хранения зависят от выбранного провайдера.

Не просите участников использовать личные пароли от других сервисов или настоящие имена.
Диалог Zico остаётся в памяти вкладки, не скачивается из интерфейса и очищается при закрытии вкладки. На сервере сохраняется факт успешного обращения, без текста.
Однако сообщение и последние восемь реплик передаются Gemini для формирования ответа.
На бесплатном уровне провайдер может использовать данные для улучшения продуктов.
Отправляйте только обезличенные учебные примеры.

Встроены ограничения в базе - до 5 запросов в минуту и 30 в сутки на аккаунт,
до 150 обращений в сутки на проект. Это внутренние пределы, они не увеличивают
бесплатную квоту Gemini. При достижении квоты показывается уведомление.
Повторные попытки входа ограничены по хешу сетевого адреса.

## Проверки и ограничения

`npm test` проверяет банк ситуаций, перемешивание, пересчёт баллов, первые попытки,
формат данных, хеширование паролей и отклонение запросов с другого сайта.
В браузере проверен локальный маршрут с ошибкой, повтором, выбором поддержки,
итогом, сохранением результата, окном Zico и исходным модулем доставки.
Реальная регистрация и запрос Gemini требуют ваших настроек и до подключения
не проверялись на живых сервисах. Серверные тесты не заменяют проверку развёртывания.

Инструкция содержит ограничения для ИИ, но модель может ошибаться. Не используйте
помощника для автоматического решения о безопасности реального сайта или аккаунта.
Не используйте приложение как экзаменационную систему с защитой от подмены результатов.

## Изменения интерфейса

Главная доступна до входа. Содержит введение, цели, карту из восьми разделов,
перечень тем и приглашение войти перед практикой. В меню модулей доступны
переходы к конкретным темам по нажатию, наведению и с клавиатуры.
Результаты и порядок прохождения находятся в меню помощи. Добавлен глоссарий.
В каждом модуле открыты теория, разобранный пример, практика и описание итогового теста.
Тест включён в конец практического маршрута и не выдаёт результат до прохождения.
Окно Zico упрощено, открывается и закрывается одной круглой кнопкой,
с плавным появлением. Кнопка наверх появляется после прокрутки и учитывает
настройку уменьшения анимации.

Сервер Zico получает от модели только категорию и номер учебной подсказки.
Текст пользователю выбирается из подготовленных формулировок в lib/zico-policy.js.
Произвольный текст модели не выводится. Есть отдельные ответы вне темы,
при нехватке данных и запросе готового решения. Такой режим ограничивает
свободные ответы модели, но ошибки классификации полностью не исключаются.
Он не подтверждает безопасность реальных сайтов или аккаунтов.
Проверка поведения с настоящим Gemini по-прежнему требуется после подключения.
